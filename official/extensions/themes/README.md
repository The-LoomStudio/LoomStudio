# 官方主题

`official.themes` 合并提供纸页、潮汐两个主题和轻动效、薄荷强调色、琥珀强调色三个增强。默认开发入口直接从本目录发现本包，可在外观设置中选择主题和增强，无需复制或安装目录。本包未列入发行包，发行默认内容保持不变。

- 一个包可以声明多个主题；同一时刻采用一个主题，增强可独立启停并排序。
- 纸页提供暖色叙事画布、包内纹理与设置图标，保留原生布局和交互。
- 潮汐提供深青底色与薄荷文字强调，“输入框圆角”支持恢复默认及跨主题保留。
- 薄荷和琥珀强调色可独立使用；同时开启时，列表靠后的增强决定强调色。个人 CSS 仍具有最终覆盖优先级。
- 主题和强调色增强是纯 CSS，无需 JavaScript 授权。轻动效支持纯 CSS 模式；授权 `motion` Client Module 后增加面板进入与退出动画。
- 包内 CSS 与素材保持相对路径，不修改用户选择的场景背景。背景图片由独立的官方背景包（本地源码位于 `official/extensions/backgrounds/`）提供。

发现、采用外观与授权代码是独立动作。官方包不能删除式卸载，可以取消采用主题和增强、停用 `motion` 模块。源码修改需要服务重新发现或重启，没有文件级 HMR。完整合同和验证边界见 [Extension 主题与样式增强](../../../docs/architecture/ui/extension-themes.md)。

从旧包迁移时，先确认本包已被发现，再移除用户安装的旧纸页、潮汐包。对应旧贡献消失后，宿主会迁移主题、增强选择、纯 CSS 模式及专属参数；旧包仍安装时继续沿用原选择。已有新包参数优先保留。旧包的代码授权不会转授给新包，使用 JavaScript 动效需要重新授权 `motion`。
