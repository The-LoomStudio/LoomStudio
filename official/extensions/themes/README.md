# 官方主题

`official.themes` 提供 Catppuccin Mocha、Nord、Everforest、Tokyo Night、Yozakura Night、靛蓝深浅色、暖灰陶橙、曜黑亮蓝和极简黑白。默认外观仍为原生银灰。

- 主题只覆盖颜色及 `color-scheme`，包含界面、状态和编辑器语法色，不改变字体、布局、圆角、背景图片或材质。
- Catppuccin Mocha 的原有紫色强调与语法色保持不变。
- 其他彩色色板参考 Odysseia Forum 的 `src/shared/styles/themes.ts`；语法色按 Loom 的语义变量适配，并非直接移植某个编辑器的高亮文件。
- 注册项 `previewColors` 按背景、面板、强调色顺序提供三个颜色；外观选择器自动显示三圆预览。未提供预览的第三方主题仍可正常选择。
- 轻动效、薄荷和琥珀增强继续独立选择；主题本身无需 JavaScript 授权。
- 纸页和潮汐不再注册。宿主确认新版官方包可用、旧主题已不存在后，将这些旧选择恢复为原生默认；仍安装的旧独立主题不受影响。

开发入口从本目录发现官方包；源码修改需要服务重新发现或重启，没有文件级 HMR。已安装的副本需更新官方主题包。包的发现、主题采用与代码授权相互独立。
