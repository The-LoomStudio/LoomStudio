# 角色包体积与目录修复

> **Status**：Completed / 已通过用户复验并归档

## 目标与事实

用户验收发现下载后缀、条目目录、重复世界书、完整 ST 源卡附件和封面残留载荷问题，授权修复。

实测四方世界 PNG 25,429,601 字节：外层含两份约 6.26 MB ST 元数据；包内头像再次保留这些数据，并有 4,692,211 字节的源卡 JSON。迷离深渊同时含大量 APNG 动画数据，不能为了减小体积破坏动画。

## 决策与范围

- 下载使用 `.loomcard.zip`，读取旧 `.loomcard` 并接受普通 ZIP；HTTP 原接口保留。
- 普通 Prompt 条目直接生成 `<名称>.md`，只有真实子树使用目录。旧索引中的 body 路径继续可读。
- 不再生成 `settings/legacy`。旧字段有独立内容时保存普通 Markdown；与资源树同 ID、同正文时复用正文文件，不静默合并或删除领域记录。
- ST 导入器只创建一次世界书资源，不再生成完整源卡 Portable Payload，头像剥离文本块和尾部载荷。
- Core 输出 PNG 头像/背景时通用移除文本块，不识别 ST 私有数据、不静态引用扩展，保留色彩和 APNG 数据。
- 已有用户数据不批量迁移或删除。旧源卡附件解绑如需执行，先核对目标与现有正式 API，明确保留原始 Document。

## 验证与边界

运行直接相关 Bundle/PNG/Server 导入/ST converter 测试；因包导出及 Client 接线改动，构建 ST、Server 并检查 Client 类型。不跑浏览器视觉验收或全仓检查。使用下载文件只读核对新旧体积，不覆盖原文件，不修改用户数据库。

PNG 内外各带一份封面是现有完整 ZIP 封装的成本；本轮不擅自改变容器引用合同，不转码或删除动画，不删除通用扩展附件。

## 结果

代码修复已完成。ST 不再生成双份世界书或完整源卡附件；新导入的 PNG 媒体移除文本块。Core 导出既有卡时同样净化媒体，不删除用户的源文件或数据库记录。普通条目直接为 `.md`，旧同 ID/正文的副本复用文件；独立内容仍保留。

实测下载文件，只读处理，未覆盖文件或写入用户数据库：

| 样本 | 原 PNG 字节 | 既有卡清理媒体后重导出 | 按修复后的 ST 转换重新导入后导出 |

| 四方世界 | 25,429,601 | 5,664,306 | 3,687,686 |
| 迷离深渊 | 39,791,634 | 28,625,111 | 26,545,959 |

重新转换会生成新的资源 ID，压缩后字节数可能有微小波动；上表为最终复测的一次结果。

两张卡的图像/动画非文本块 Hash 均一致。迷离深渊保留 76 帧，纯图像本身 11,315,891 字节；仍存在完整 ZIP 与外层 PNG 双份封面的成本，未擅自修改协议。
