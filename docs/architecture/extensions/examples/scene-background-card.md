# 场景背景卡

[下载或查看单文件脚本](./scene-background-card.loom.js)。这是可编辑的 Client UI 示例，用于验证跨扩展背景资源读取、Renderer 挂载、切图和卸载。它不更改工作台背景、State 或剧情内容。

## 在工作台使用

1. 确认安装了 `official.backgrounds` 官方背景资源包。
2. 在扩展面板的“脚本”页导入 `scene-background-card.loom.js`，添加到全局或当前角色。
3. 授予 `runtime.client` 和 `assets.read`，再启用。保存或导入本身不会启动脚本。
4. 打开故事，卡片出现在聊天时间线末尾。切换图片、点击图片展开大图，或展开“资源信息”检查来源、资源标识、地址与加载状态。

脚本顶部的 `backgroundPackage`、`title` 和 `description` 可直接修改；保存后点击“刷新此实例”采用新代码。停用或刷新会关闭展开图并卸载旧卡片及事件监听器。

`ctx.backgrounds.list()` 返回当前宿主背景目录的快照，包括包身份、资源键、名称和已解析的图片 URL。此示例仅筛选官方包，不猜安装目录、不固定包版本。缺包时显示空状态；安装或卸载背景包后点击卡片内“刷新资源”重新读取目录。图片加载错误单独显示，不伪装成缺包。

该读取需要 `assets.read`；仅返回全局与当前角色可见背景。它不授予背景注册、背景切换、任意包文件读取或跨包 RPC 权限。Client 代码本身属于受信任主窗口执行，Shadow DOM 只隔离样式，不是安全沙箱。

## 开发预览与验证范围

打开 `/dev/preview/scene-card`。预览使用同一份脚本、正式 Script Runtime 与 RendererSurfaceHost，图片取自仓库中的官方包；目录数据为内存样例，不代表已经安装到当前工作台。可以停用、启用、刷新实例、模拟缺包，并下载脚本。不会调用业务 API 或修改用户数据。

定向测试覆盖 Metadata、资源授权、当前角色过滤、快照隔离、版本化包地址、切图、迟到图片事件、缺包与停用清理。大图和实际图片加载的视觉效果仍需在浏览器中确认。

## 实际工作台开发热更新

扩展 → 脚本 →“场景卡示例”可直接创建草稿，无须先到预览页。保存、添加采用、授权并启用后，在当前 Mount 勾选“开发联调”。Vite 会监听 `docs/architecture/extensions/examples/scene-background-card.loom.js`，只替换已选中的运行实例，不刷新整页，不写数据库版本。卡片局部选择等运行内存会随重新激活重置。

关闭联调恢复已采用源码；刷新页面会退出联调。普通脚本保存仍不重启。热更新仅支持代码/样式修改，Metadata 变化明确拒绝，需退出联调后按正式保存与授权流程采用。当前联调只针对这个固定示例，不是任意服务器路径执行接口。
