# Agent Architecture

本分类收录 Studio Application 中 Agent 的稳定领域架构，包括 Agent 身份、运行策略、Runtime Transcript、Tool/Capability、检索、权限和产出提交边界。

Agent 是执行工作的主体，不等于 Character。Kernel 不理解 Agent、Tool 或 Narrative 语义。

当前 Agent 设计仍处于演进阶段，保留在 [`../../../workbench/discussion/application/agent/`](../../../workbench/discussion/application/agent/)。本目录只预制正式归属，不提前晋升候选模型。
