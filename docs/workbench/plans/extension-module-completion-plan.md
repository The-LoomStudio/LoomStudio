## 已确认边界与授权

- 宿主安装不执行依赖安装或作者构建脚本；TS / React / Vue 所需成品由作者发行提供。
- Git 不依赖 GitHub 专属接口；ZIP 没有 Git 时仍可安装，不显示虚假的自动更新能力。
- 原安装、授权和数据所有权规则保持；代码更新不顺带覆盖扩展 SQL / 文件数据或已有作者资源。
- 官方选择允许跳过，失败不阻断游玩；新权限不能因升级或官方身份而自动授权。
- 本次只整理后续。远程下载、凭据、独立仓库同步、发布及真实用户安装操作仍须处于明确授权范围。
