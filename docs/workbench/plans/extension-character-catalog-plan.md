## 仅保留的后续

- **W4 远程按需角色目录**：浏览不创建 Card，选定后下载、预检并显式导入。来源身份、内容摘要、失败恢复及更新采用与[资源下载更新](./resource-download-and-update-plan.md)统一收束，不另建作者平台或自动同步。
- **W5 跨包 RPC 与独立脚本依赖**：保留调用者身份和 Card 上下文，分别声明路由目标；核对依赖、版本、提供者运行状态、公开方法与授权。脚本 Owner、采用版本与执行生命周期须与[Script 计划](./loom-script-distribution-and-runtime-plan.md)对齐，不改变 @require 的既有含义。

依赖存在不等于自动启动或授权。完成标准是按冻结合同验证跨范围拒绝、缺失/版本不符、更新卸载及调用者身份；在合同确定前不展开施工。角色模板更新不能覆盖用户已导入的 Card。
