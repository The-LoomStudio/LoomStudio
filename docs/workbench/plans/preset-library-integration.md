## 接入边界

- 共享 `PresetLibraryCatalog` 与 `PresetConfigurationDialog`，预览与正式入口复用；2026-10-26 根据用户确认，目录改为单栏分组列表，取消来源侧栏与对应的列表详情区。个人预设直接列出；官方、扩展分组下的来源默认展开，可手动收起；搜索更新时展开匹配来源。移动端使用同一层级，无来源下钻。
- Widget 以现有 PromptResource、安装来源、Lore/工具挂载生成目录展示；不引入预览 Schema、不改持久化。
- 目录行主体（名称、图标、摘要）进入消息编排；只有显式“配置”按钮打开浮层。编排保留根节点作为追加 Message 的入口；每次进入或切换预设默认展开根节点和 Message，之后保留手动折叠。不可拖拽的根节点与可拖拽条目共用拖拽列宽度，保证层级线和展开箭头对齐。
- 配置浮层复用 AgentModelEditor、Lore 挂载、PresetTextUses 和工具挂载；模型与审批、Lore、正则/提取器、工具在顶部并列。仅展示真实存在的配置能力，不将预览里的脚本/模块样例冒充正式预设绑定。
- 配置即时保存。保存中限制重复写入与关闭；失败保持可见、可重试。原有预设 CAS 版本与不可用引用保留。
- 编排下钻复用 ContextAssetExplorer/Editor，只显示当前预设的树；深链接、搜索定位、导入导出和节点操作保留。
- 本次不实现新的跨预设复制协议或扩展包迁移；现有复制/导入导出操作继续使用原合同。
