# 官方背景与面板材质

> **状态**：Approved Direction / 实施前收口
> **日期**：2026-09-12
> **授权边界**：已批准从背景讨论稿晋升 Plan，并将背景与毛玻璃材质作为同一交付；本轮仅整理文档，未授权代码实施。下文标为建议或开放问题的内容尚未冻结。

## 目标

提供第一方背景控制与配套面板材质，使静态图片和扩展动态背景都能通过前景正确呈现。背景选择、透明度、模糊、可读性、保存与恢复形成一个闭环；不能以“背景已经挂载”替代完成交付。

## 已确认事实

- [Studio Stage](../../../../apps/studio-client/src/pages/studio/studio-page.module.scss) 已有背景层、裁切、独立层级与禁用指针命中，基础聊天层透明。
- [App](../../../../apps/studio-client/src/app/app.tsx) 已挂载 Workspace Scope 的 `shell.background`。
- [Renderer Host](../../../../apps/studio-client/src/features/extension-renderers/model/client-renderer-host.ts) 已有独占、显式替换、释放和实例生命周期；占用记录目前是内存态，不等于持久背景偏好。
- [Client Renderer 合同](../../../architecture/extensions/client-renderer-host.md) 尚无正式宿主材质控制；Workspace Renderer Context 没有完整活动 Timeline / Branch 信息。
- [Layout Store](../../../../apps/studio-client/src/pages/studio/model/studio-layout-store.ts) 已有客户端偏好持久化模式；未实现官方背景选择和材质设置闭环。
- 背景 Demo 的安装与声明有自动化记录，但最终浏览器效果未完成统一验收。不能将观察稿中的描述视为本计划验证结果。

## 决策

1. 背景与面板材质共同设计、实施和验收。毛玻璃是正式范围，不是后续增强项。
2. Renderer 负责背景内容，宿主负责材质、可读性和用户控制。复用 `shell.background`，不新增平行背景宿主。
3. 底色 alpha 与模糊强度分别控制；不以整个容器的 opacity 控制材质，避免文字与按钮一起变淡。
4. 不把全部 surface 颜色 Token 改成透明，不给每层嵌套控件或每条消息机械增加滤镜。保留实色选择，Custom CSS 内容不被官方设置重写。
5. 扩展页面、声明式设置与组件使用能力归 [Extension DX Plan](../extension-developer-experience.md#3-扩展页面声明式设置与组件使用)，不作为本计划前置。

## 实现约束

布局容器、材质背板和内容分别承担布局、采样和交互职责，不要求一律增加三层 DOM。遵守 [CSS 与主题合同](../../../architecture/ui/css-and-theming.md)，不通过大块关键伪元素、任意全局 CSS 注入或极大 z-index 修补。

材质背板与滚动内容分离；一块面板优先一个背板。滤镜、祖先 opacity、mask、clip-path、混合模式和相关 will-change 可能改变背景采样边界；stacking context 不等于 Backdrop Root，不能把问题统一归因于 z-index 或 transform。开关动画、Portal 和嵌套表面必须结合目标浏览器核对。

材质 Token 只表达底色、模糊、边界及实色模式等稳定角色，命名在实现设计时冻结。参数只作用于明确选定区域，不靠无边界继承传播到所有输入框与弹窗。`@supports` 只能说明属性支持，不能证明采样正确。

## 开放问题与建议

| 待收口事项 | 建议起点，尚非已批准合同 |
|---|---|
| 偏好归属与图片来源 | 客户端外观偏好复用现有持久化模式；图片引用已有 Asset，本地导入须核对现有入口与资源生命周期，不把字节塞进偏好存储 |
| 背景选择与恢复 | 一次显示一个来源；保存官方背景选择，扩展停用或失效后恢复；须明确“主动关闭”与“临时替换”的区别，以及重启后是否重新打开扩展 |
| 材质覆盖区域 | 聊天阅读区、输入区、主工作面板；弹窗先保持实色，具体边界由代表性样板确认 |
| 默认效果 | 首次开启背景提供配套毛玻璃配置，用户可调整或选择实色；不覆盖用户已经保存的材质选择；数值由样板确认 |
| 资源范围与失败 | 首版本地图片／已有 Asset 和已注册 Renderer；不默认扩展到远程 URL 与视频；定义图片缺失、Renderer 异常时的可解释恢复 |
| 浏览器与降级 | 确认目标桌面／移动浏览器；减少动态效果、滤镜不可用、对比度和键盘行为纳入验收，不承诺未经测量的帧率 |

The World 所需的活动 Timeline / Branch、切换取消与过期读取丢弃，在迁移接线前单独冻结到扩展上下文合同。静态背景和材质不依赖该能力，不把世界状态归入外观偏好。

## 非目标

不建设 Background Stack、万能 CSS API、完整主题引擎、扩展表单系统、远程素材市场或强沙箱；不实施 The World 状态、地图、音频和旧指令迁移。

## 验证预算与停止条件

- 文档阶段仅检查本次 Diff、相对链接和归属一致性，不跑应用测试。
- 实施时用最小定向检查覆盖偏好恢复、显式替换及停用／异常恢复；公共类型变化才补对应 package 类型检查，不默认跑全仓套件。
- 客观浏览器诊断聚焦采样、层级、尺寸、命中、滚动与动画期间行为；包含带纹理静态背景和动态 Renderer。性能只在具体效果出现风险时测量。
- 人工验收覆盖模糊真实生效、文字对比度、开关动画、滚动、弹窗、移动布局和操作手感；自动检查不替代用户判断。
- 产品边界未冻结时不实施依赖它的接线；新增依赖、跨模块架构调整或资源迁移超出范围时停止收口。主要风险已覆盖且无未解释结果时停止追加检查。
