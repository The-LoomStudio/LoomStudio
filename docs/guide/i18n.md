# 国际化指南 (i18n)

Loom Studio Client 默认支持双语环境：`zh-CN` (默认与优先) 以及 `en-US`。
我们不使用过度复杂的 i18n 第三方库，而是依赖简单的 Context 与字典对象。

## 文件位置
所有的词条字典存放在：
- `apps/studio-client/src/shared/i18n/zh-CN.ts`
- `apps/studio-client/src/shared/i18n/en-US.ts`

## 开发规范

### 1. 以中文为第一公民
在添加新功能时，如果时间紧迫，**可以先只编写 zh-CN 的翻译，将 en-US 的对应 key 留为空字符串或直接回退到中文**。
不要因为阻碍你编写英文翻译而拖延功能交付。

### 2. 避免在 UI 代码中硬编码中文字符
> 唯一允许硬编码中文的例外情况是：高度临时性的 PoC（概念验证）页面，或者只有极少数特定人群会看到的 debug 内部面板。
在任何面向用户的正式组件中，使用 i18n hook。

```tsx
import { useTranslation } from '@/shared/i18n'

export function MyComponent() {
  const { t } = useTranslation()
  return <div>{t('common.confirm')}</div>
}
```

### 3. Key 的命名
按所属功能块或页面进行嵌套，例如：
`promptBuilder.actions.compile` 或 `cards.list.emptyState`。
请不要过度复用那些在不同语境下可能有不同翻译的单词（如不要全系统只用一个 `open`，它可能是“打开”也可能是“开放”）。
