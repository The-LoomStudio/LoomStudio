当前归属（2026-10-25）：本目录仅保留预览宿主、预览 Composer 与演示组合。正式轮次投影和展示模型位于 `features/narrative-runtime/model`，执行流与沟通组件位于其 `ui`；正式 Timeline 与预览共同消费这些组件。下文保留交互决策与既有验收记录。

状态：2026-10-24 Dev Preview 展示实验；正式 Timeline 已复用工作过程与轮次沟通组件；输入框沿用原有 ChatComposer。预览控制器仍只使用内存，UI Props 不定义持久化或 Runtime 合同。

入口：`/dev/preview/narrative-session`。默认展示一轮约 1200 字正文；点击「重播示例」观察开场思考逐步增长、工具调用和多段逐步输出，暂停后可用「推进一步」检查阶段。`?scene=empty` 为空白，`?scene=long` 为多轮历史，`?scene=communication` 为两轮沟通回看样例。[预览控制器](../narrative-session-preview.tsx) 和[长正文样例](../narrative-session-samples.ts) 只使用内存，不调用真实模型或写入业务数据。

## 阅读与过程细节

[NarrativeExecutionFlow](../../features/narrative-runtime/ui/narrative-execution-flow.tsx) 使用三级细节：轻量工作入口 → 原顺序的思考/工具短行 → 单条思考内容或工具参数/结果。

- 默认不在正文之间留下过程占位、完成标记、重复的「剧情」标题或分割线。多个正文输出保持正常段落间距。
- 工作期间直接展示当前工作段：思考内容默认展开并随样例逐步增长，工具调用逐条显示短行，参数/结果点击查看。过程不会从一开始就藏在总入口里。
- 后续一段正文或普通回复输出完成后，前面的工作段才自动收入统一入口；正文流式输出期间继续保留。执行结束也会收起最后的工作段。正文之后的新工具/思考会重新直接展示。完成阅读时只保留一个工作入口。
- 展开入口后，过程行回到各自的原始位置，可追溯「工具 → 正文 → 工具 → 正文」；进一步展开具体记录才显示内容。手动展开状态不随新正文或执行完成被强制关闭。
- 普通回复和询问放在独立的创作沟通区域；不与正文或工具过程混排。`presentation: 'question'` 仍只是展示提示，不代表工具 Surface、审批或新增 Narrative 类型。
- 用户向上阅读或手动展开过程后暂停自动跟随，提供「回到最新进度」。手动查看具体记录也会保留整个过程视图，避免后续输出将正在查看的记录自动隐藏。暂停模拟和手动推进仅属于开发控制。

多段样例中的修订按正文段分别更新，避免完整修订稿复制到每个输出块。Swipe/候选恢复沿用原预览的内存模拟。

## 轮次沟通

[NarrativeCommunication](../../features/narrative-runtime/ui/narrative-communication.tsx) 将写作执行中的普通回复/询问，以及同候选下的用户指导、讨论执行组织在一起，与正文左侧对齐，通过字号、角色名和间距区分正文，展开区不重复显示标题和轮次说明；没有侧线、外层缩进或逐条卡片。

- 沟通入口始终显示为单个图标，即使当前还没有沟通记录也可打开。沟通默认收起；打开后位于所属正文下方的滚动流，没有独立滚动容器。正式页沿用既有正文操作栏承载沟通图标和 Swipe。
- 当前与历史轮次均通过图标原位展开/收起，切到沟通模式时自动展开已有记录，随后仍可通过图标独立收起；切回扮演会收起全部沟通。点击当前沟通里的「回复」切到沟通模式并聚焦输入框。「回到当前轮」只滚回最新位置，不改变模式、草稿或发送目标。
- 开启下一轮后，旧沟通随原轮次保留为历史入口。换候选时显示该候选的沟通，不串入其他候选的指导。
- 预览的正文 Flow 使用 `hideReplies` 避免重复显示沟通。此展示选项默认关闭，不改变其他调用方的默认行为；没有根据文本内容猜测或吞掉模型的完成报告。

验证：Client TypeScript 无输出检查、临时 DOM 交互探针及 Vite SCSS 转换通过。探针覆盖沟通属于正文滚动流、历史就地展开、草稿与发送目标保持、开启下一轮后的沟通归属，以及开场思考逐步显示、工具行直接可见、正文写完才折叠、后续工作重新显示、单入口、三级细节、展开后的原顺序、手动展开保留、纯阅读中的询问、暂停/推进、长正文、多段修订和候选恢复；未观察到网络或持久 Storage 写入，卸载清理定时器。没有进行浏览器主观视觉验收或真实模型验证。

## 正式页面接线

正式 Timeline 按轮虚拟化，复用 `NarrativeExecutionFlow` 与 `NarrativeCommunication`；正式输入框使用原有 `ChatComposer`，不套用草稿的 Composer 外观。正文仍经过已有 Display、正则、宏与扩展 Renderer，保留编辑、链接、楼号导航及 Swipe。Entry 的轮次/候选身份用于归属，正文修订保留原阅读位置；仅投影已加载正文所在的轮次，不把更早的工作历史单独堆在当前页。

扮演／沟通切换在输入框下方工具区的第一个位置，替代输入区的侧栏展开按钮；侧栏沿用导航入口。切换保留两份临时草稿并聚焦同一输入框。上方不再显示模式切换栏，也不展示声明式／短对话自动的选择；本次只调整 UI，不改变现有 Runtime 输出规则。预设选择与暂停／继续也由底部输入框承载。

## 流式阅读（2026-10-24，预览已确认并接入正式界面）

沿用 `/dev/preview/narrative-session`，`?scene=streaming` 自动启动一轮长思考 → 工具参数增长 → 正文 → 再思考/工具 → 第二段正文。原 `empty`、`long`、`communication` 场景保留。顶部可选慢速、均匀、突发输出；保留暂停与单步推进，并在均匀流中加入确定性停顿。速度是样例调度，不代表模型吞吐测量或正式输出缓冲算法。

正文使用正式 `MessageContent`；右侧使用正式 `AgentChatPanel` 和独立内存播放控制，可点击「重播副 Session」。侧栏不调用业务 API，关闭后卸载样例并取消计时器。开发入口在导入共享 Widget 前将本页 localStorage/sessionStorage 隔离为内存，正式启动路径不变。

`shared/ui/streaming-viewport/` 提供按需运行的平滑跟随和限高内容区域。思考与工具详情最大高度为 `min(320px, 40dvh)`；内层滚动使用 `overscroll-behavior: contain`，外层不响应内层的滚轮/触摸/键盘滚动。上翻、划词暂停跟随，按钮恢复；聚焦详情或主动展开过程会暂停外层。思考结束不立即折叠，仍按既有规则在后续输出完成时收起，手动展开保持。

新行为通过 `NarrativeExecutionFlow.followWork` 和 `AgentChatPanel.smoothFollow` 由预览和正式调用方启用。Timeline 外层与副 Session 外层均使用同一平滑跟随控制器。副 Session 的虚拟列表在平滑模式下关闭自身末端锚定/追加跟随，由同一个平滑控制器接管；既有模式保持原行为。生成中的副 Session 思考/工具详情自动展开，落盘后保留该实例的展开状态；已有历史不全部默认展开，用户可手动关闭。

本批未实现：Streamdown/Remend 接入、未完成 Markdown 的稳定补全、展示缓冲与字素调度、iframe 增量更新/执行边界，以及失败/取消场景。正式页面已启用；真实模型账户的运行手感仍待人工验收。

### 正式 API 接线

底层继续使用仓库现有 Vercel AI SDK `streamText().fullStream`，由 Gateway 转换 `reasoning-delta`、`text-delta`、`tool-input-delta`，Runtime 补齐 Run/Provider Step，再通过 `agent.run.subscribe` 游标 API 交给 `agent-run-observer.ts`。不增加第二条流式接口，也不改变持久化格式。

前端观察器在缺少占位的重连场景中按收到的真实增量创建正文；实时正文标记为 `partial`，工具或正文开始时结束当前思考的运行指示。`retainRunPresentation` 将思考、正文和工具的临时展示身份转交正式记录，不用历史内容冒充当前流。Timeline 自动正文模式直接展示正文增量，讨论执行的回复仍归沟通区域。后台历史刷新不覆盖正在由 Run 观察器维护的临时增量；Run 终结后仍权威重读历史。

用户在思考区上翻、划词或聚焦时暂停外层，并保留已查看过程；后续正文完成不能自动隐藏正在查看的思考。锚点导航暂停跟随，“回到最新进度”恢复同一个控制器；Timeline/分支切换沿用正式页已有实例 key 隔离。

验证：SDK 网络边界提供受控 SSE，实际经过 SDK、Runtime、Run Service 与前端观察器的贯通用例通过，覆盖未创建正文占位的重连、思考→正文、临时/正式展示身份。相关 Client/Run/SDK 定向测试、Client TypeScript 与 Vite 生产构建通过。独立正式浏览器页停在首次设置，未改动设置或发送真实账户模型请求；不将测试环境链路等同于真实账户端到端验收。

进入沟通模式默认展开当前已加载历史中有记录的沟通，避免重复点击；空沟通入口不批量展开。留在沟通模式期间手动收起会保留选择，切回扮演自动收起全部沟通，再次进入沟通会重新展开已有记录。沟通模式下稍后加载的历史记录也按默认展开处理。正式页与预览复用同一个展开状态 Hook。

### 原生上滑与刷新恢复（2026-10-24）

滚动释放不再依赖外层先收到 wheel/touch/pointer 事件：iframe 内的输入不冒泡、原生滚动条或键盘也可能只改变外层 scrollTop。控制器比较实际位置与自身动画写入，观察到额外向上移动就停止跟随；内容收缩将位置钳制到新底部时不误判为用户上翻。

正式 Timeline/副 Session 在当前浏览器历史项中分别记录阅读位置，只含 endpoint/Timeline/Branch 或 Session 范围、虚拟行身份、行内偏移、跟随状态及正文锚点，不写故事数据库、localStorage 或 Session 工作历史。首次进入无记录时显示最新；原先上翻阅读时刷新恢复原位置并保持暂停跟随。显式楼层链接优先。恢复等待虚拟行实际测量，包括 iframe 延迟测高；更早的正文通过既有锚点分页读取路径定位，用户重新操作可取消等待。预览未传恢复范围，因此不读写浏览器历史项。

定向浏览器诊断使用同一正式 viewport、TanStack Virtual 和 sandbox iframe：最大偏移 1439px，真实从 iframe 内上滑到 718.5px 后暂停且不回弹；刷新后仍为 718.5px、暂停跟随。独立入口和步骤见 `tests/probes/client/stream-follow.md`。本轮未运行真实账户模型请求。
